Paramètres

Les clés API restent dans le stockage local de ce navigateur — jamais synchronisées, jamais envoyées ailleurs qu'au fournisseur.

Langue de l'interface

S'applique au popup, à cette page et à la barre flottante. Les langues de doublage se choisissent à part.

Traduction en ligne

Utilisé seulement quand la traduction locale de Chrome est indisponible. « Automatique » n'exige aucune clé.

Les clés sont enregistrées dès la saisie, uniquement sur cet appareil.

Glossaire

Un terme par ligne. « terme = traduction » impose cette traduction ; un terme seul est conservé tel quel, jamais traduit. Appliqué avec tous les moteurs, Pro compris.

Sites désactivés

Voxylio restera totalement inactif sur ces sites — aucune détection de vidéo, aucun menu flottant.
